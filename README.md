# Trender

한·일·영 AI/테크 트렌드를 자동 수집해 **언어권별 시각으로 따로** 리포트를 만드는 프로젝트.

## 어디서 긁어오는가

- 한국어·일본어·영어로 운영되는 AI/테크 매체의 RSS 피드
- 같은 사이트라도 본문이 짧게 잘려 들어오는 경우, 페이지를 직접 가서 본문을 보강 수집
- 새 키워드가 빈도 있게 등장하면 자동으로 새 후보 소스로 등록해 시간이 갈수록 커버리지가 넓어진다

## 어떻게 제공되는가

- 각 기사에서 **원어 그대로의 키워드만** LLM이 정밀 추출해 색인화 (요약하지 않는다)
- 매일·매주 한 번씩, ko/ja/en 세 언어로 **각 언어 기사만 가지고 그 언어로** 마크다운 트렌드 리포트를 자동 생성
- 결과는 웹 대시보드(`/`)에서 언어 탭으로 확인 — 같은 기간의 한국·일본·영어권 담론이 어떻게 다른지 한눈에 비교할 수 있다
